# SIMA — Sistema Integrado de Monitoramento e Gestão de Configuração para Máquinas Agrícolas

Repositório da atividade de Arquitetura de Software — Diagrama de Contexto (C4 Model, Nível 1).

## Estrutura

```
.vscode/         # Configurações de extensões recomendadas
diagrams/        # Diagramas como código (Mermaid e PlantUML)
docs.md          # Documentação completa da atividade
README.md        # Este arquivo
```

## Como visualizar os diagramas

### Mermaid (`sima-context.mmd`)

**Opção 1 — VS Code**
Instale a extensão [Mermaid Preview](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid) e abra o arquivo `.mmd`.

**Opção 2 — Online**
Acesse [mermaid.live](https://mermaid.live), cole o conteúdo do arquivo e visualize o diagrama.

**Opção 3 — GitHub**
O GitHub renderiza Mermaid nativamente em arquivos `.md`. Basta colar o código em um bloco de código com a linguagem `mermaid`.

---

### PlantUML (`sima-context.puml`)

**Opção 1 — VS Code**
Instale a extensão [PlantUML](https://marketplace.visualstudio.com/items?itemName=jebbs.plantuml). As configurações do servidor já estão em `.vscode/settings.json`. Abra o arquivo `.puml` e pressione `Alt+D` para visualizar.

**Opção 2 — Online**
Acesse [plantuml.com/plantuml/uml](https://www.plantuml.com/plantuml/uml) e cole o conteúdo do arquivo.

**Opção 3 — Kroki**
Acesse [kroki.io](https://kroki.io), selecione PlantUML e cole o conteúdo.
